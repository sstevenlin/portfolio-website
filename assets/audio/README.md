# Audio Files for Music Player

To add your own songs to the music player:

1. Add your audio files (MP3, WAV, etc.) to this folder
2. Update the `audioUrl` in each song object in `app.js`
3. Use relative paths like: `"assets/audio/your-song.mp3"`

## Demo Audio

Currently using demo audio files for testing. Replace with your actual music files.

## Supported Formats

- MP3 (recommended)
- WAV
- OGG
- M4A

## File Size Recommendations

- Keep files under 5MB for good loading performance
- Use MP3 128kbps for good quality/size balance
